# Inactive Firebase configuration

These files preserve the former Firebase rules, indexes, emulator ports, and
named-database configuration verbatim. The supported application and CI use
Supabase; this directory is historical reference, not a deployment entrypoint.

Moving this configuration does not modify or retire any hosted Firebase service.
No external Firebase project status was checked during the repository cleanup.
If the former deployment must be recovered, review its current ownership and data
before using these files. The configuration paths are relative to this directory.
